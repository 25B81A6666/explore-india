# Explore India – Travel Destination Website

## About the Project

Explore India is a simple travel destination website created as a mini project using HTML and CSS. The website presents some popular places in India along with images and short descriptions.

## Destinations

The website includes:

* Goa
* Manali
* Jaipur
* Kerala
* Gujarat

## Technologies Used

* HTML
* CSS

## Features

* Simple navigation bar
* Hero section
* Popular destination cards
* Destination images and descriptions
* Hover effects on destination cards
* About Us section
* Contact section
* Background image and responsive card layout

## How to Run

1. Download or clone this repository.
2. Keep all the HTML and image files in the same folder.
3. Open `index.html` in a web browser.

## Project

This project was created as part of my academic work to practice HTML and CSS and to learn how to build a basic travel website.
